# Security

If you find a security or privacy problem in Document Vault (for example, a kind of sensitive number that the masking does not hide), please report it privately:

- On GitHub, go to the **Security** tab of https://github.com/cudjo21/document-vault and choose **Report a vulnerability**.

Please do not post real document contents or personal numbers in a public issue. Describe the pattern instead (for example "14-digit number followed by /04").

Fixes are released as a new version; users get them with **Update** on the plugin marketplace.
